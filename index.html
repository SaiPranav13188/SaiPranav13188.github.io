Engineering decisions

Calls I'd defend

Shipping is mostly trade-offs. These are four I made on purpose, along with what each one cost.

Nagrik

Hand OTPs back to the citizen. Never bypass them.

Problem
The real municipal portal asks for a mobile OTP before the complaint form even appears.
Choice
Check for CAPTCHAs and OTPs before filling a form and again after submitting it. If one appears, give the citizen a three-step hand-off. Monitoring and escalation still run automatically.
Cost
Filing isn't fully hands-off on gated portals, but the agents never automate their way around a human check.
Read the reasoning ↗
Bytewise

Never delete anything. Move it to a holding area.

Problem
If a cleanup tool gets it wrong even once, someone's files are gone for good.
Choice
Moves are logged and can be undone for 30 days. Rules for user data and system folders are checked first, so no later rule can mark anything inside them as safe.
Cost
Space isn't freed until the holding period ends or you confirm, and that's the point.
Read the reasoning ↗
BondCheck

Every value needs a quote, or it gets dropped.

Problem
LLM extraction invents plausible numbers, and a fake bond penalty could change someone's career decision.
Choice
verify_quote() checks that every quote exists in the redacted letter, and plain Python re-derives each value from its quote.
Cost
Some true values get dropped and sent to the uploader to confirm, trading recall for accuracy. Hallucinated fields fell from 22 to 0.
Read the reasoning ↗
Tally

Raw bank SMS never leaves the phone.

Problem
Bank messages are some of the most sensitive data on a phone, and sending them to a server to parse is the easy route.
Choice
Parse on the device and keep only the last four digits of accounts. The AI fallback is opt-in and masks text twice, on the phone and on the server.
Cost
Every bank needs its own parser and test fixtures, instead of a single LLM call.

How I work

01

Guardrails in code, not prompts

Models choose what to do next. The rules about what they're allowed to do are enforced in the tools, so a model can't talk its way past them.

02

Measure, then claim

Eval harnesses, pinned reference values and test suites come first, and I write down the known limits next to the results.

03

Ship the whole thing

From the agent graph to the database, the mobile app, the deployment and the README, every project is something people can actually use.
