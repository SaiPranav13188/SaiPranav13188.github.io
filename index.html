About

I'm a software engineer who likes the hard part of AI: making it reliable. Most of what I build is multi-agent systems where the model plans and calls tools, while the safety rules live in code it can't talk its way around. Every extracted value has to be backed by a quote, every tool call is logged, and a person stays in the loop for anything risky.

I take projects from idea to something you can actually install, including native macOS apps in Swift, Android apps in Kotlin, Expo / React Native mobile apps, and Next.js front ends on FastAPI, Express and Supabase back ends. Before that I worked on machine learning and data projects. My PySpark crop-recommendation system won a Dean's Award.

I write tests, measure what I claim, and document what doesn't work yet.

Featured work

  1. Oct 2026

    Bytewise · macOS disk analyzer ↗

    A native macOS app that shows where your disk space went, explains each location in plain words, and cleans up safely. Nothing is deleted without a preview, and every move can be undone.

    • Squarified treemap drawn with SwiftUI Canvas. Layout for a 1200×800 window takes under 1 ms.
    • Scans ~84,000 files/s. Sizes match du on two of three test folders; the third differs slightly because of hard links.
    • Finds AI models (Ollama, Hugging Face, LM Studio) that quietly take up tens of GB. 79 test cases, sandboxed, and nothing leaves the Mac.
    • Swift
    • SwiftUI
    • macOS
    • XCTest
  2. Oct 2026

    BondCheck · agentic job-bond transparency ↗

    Seven specialised AI agents read anonymously uploaded offer letters, redact personal data, extract and verify job-bond terms, and warn graduating students before they sign.

    • LangGraph orchestrator with retries, token budgets and human-in-the-loop interrupt().
    • A quote-verified self-check loop raised field accuracy from 88.5% to 99.6% and cut hallucinated fields from 22 to 0 on a 50-letter synthetic benchmark.
    • 0 of 335 planted personal details leaked. Q&A uses read-only, allow-listed SQL and cites its sources.
    • LangGraph
    • Claude API
    • FastAPI
    • PostgreSQL
    • Next.js
    Live site ↗ Source ↗
  3. Sep 2026

    Nagrik · AI agents for civic complaints ↗

    Take a photo of a civic problem. Agents classify it, work out which government office is responsible, write a formal complaint, file it on the official portal with a headless browser, then follow up and escalate when nothing happens.

    • Five agents built on AI SDK tool loops: intake (Gemini vision), jurisdiction, drafting, Playwright submission, and monitoring and escalation.
    • CAPTCHAs and OTPs are always handed back to the citizen, never bypassed. Escalations go only to verified contacts.
    • Expo app in English, Telugu and Hindi. Runs fully offline with a rule-based planner when no API keys are set.
    • TypeScript
    • Expo
    • Express
    • Playwright
    • Gemini
    • Supabase
  4. Sep 2026

    Journi · AI travel planner ↗

    A mobile app that plans trips day by day using live weather and exchange rates, then lets you refine the plan by chatting. Group trips use an agent that balances everyone's preferences.

    • Six tool-calling agents (orchestrator, planner, budget, ticket reader, price check, weather watcher) with zod-validated JSON output.
    • The group agent runs polls for disagreements and splits expenses Splitwise-style, with live sync over Supabase Realtime.
    • Built-in eval harness compares v1 and v2 agents on 14 refinement cases. Guardrails are enforced in code, not just in prompts.
    • React Native
    • Expo
    • Express
    • Gemini
    • Vercel AI SDK
    • Supabase
  5. Oct 2026

    Tally · expense tracking from bank SMS ↗Private repo

    An Android app that turns the transaction SMS your bank already sends into a full expense tracker. It comes with a web dashboard and an AI agent that answers questions about your money.

    • Parses SMS on the device, so raw messages never leave the phone. OTPs are never stored, and only the last 4 digits of accounts are kept.
    • Detects subscriptions, sends alerts for unusual or double charges, tracks budgets, handles split-and-owe with automatic UPI settlement, and includes a home-screen widget.
    • FastAPI agent with Gemini function calling answers from real numbers, under row-level security (RLS).
    • Kotlin
    • Jetpack Compose
    • FastAPI
    • Next.js
    • Supabase

  6. Oct 2026

    Handsoff · send files with hand gestures ↗

    Make a fist over a photo to grab it and open your hand to send it. On the other device, open your palm to receive it.

    • MediaPipe hand tracking with smoothing, hysteresis and a 5-frame streak, so flicker never fires a gesture.
    • Native Android app works phone-to-phone over Nearby Connections with no internet. The web version pairs through a QR code and a WebSocket relay.
    • Released as v1.0.0 APK, with tests for byte-for-byte transfer.
    • Kotlin
    • MediaPipe
    • Next.js
    • WebSockets
  7. Sep 2026

    NutriSnap · AI calorie tracker ↗

    Photograph a meal and a vision model identifies the dish, breaks it into ingredients, and logs macros against a target calculated from your body and goal.

    • A pnpm monorepo where web, iOS and Android share one calorie engine, covered by 70 unit tests pinned to published reference values.
    • Uses structured output: the response schema is generated from Zod and validated again before the result is trusted.
